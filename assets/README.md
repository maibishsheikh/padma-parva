# PADMA PARV – ASSETS FOLDER GUIDE

Place your client assets directly in this folder (`assets/`). The website is designed to automatically detect and display them:

| File Name | Description | Mandatory / Optional | Fallback Behavior if Not Present |
|-----------|-------------|----------------------|-----------------------------------|
| `intro-video.mp4` | Cinematic introductory video played after clicking the card | Recommended | Shows graceful transition screen with "पुढे जा (Skip Intro)" to open the book |
| `invitation-reference.jpeg` | Original invitation reference image (showing Padma ji, forts, Maharaj) | Recommended (Page 1) | Shows majestic Sahyadri mountain & fort skyline SVG artwork with waving saffron flag |
| `padma-logo.png` | Official "पद्म पर्व" logo | Recommended (Page 2) | Displays high-resolution royal Devanagari gold embossed typography & crest |
| `shivaji-portrait.png` | Chhatrapati Shivaji Maharaj portrait | Optional | Integrated in page styling |
| `fort-background.jpg` | Sahyadri fort background landscape | Optional | Styled parchment paper texture & SVG fort silhouettes |
| `decorative-border.png` | Traditional Maratha ornate border | Optional | CSS-based 24K gold filigree corners & double borders |
| `additional-images/` | Any extra photographs of Padma ji's 100-fort expedition | Optional | Place high-res photos here |

### Supported formats:
- Video: `.mp4` (H.264 / AAC encoded)
- Images: `.png`, `.jpg`, `.jpeg`, `.webp`
